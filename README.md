# Precious & Kristopher · Introduction Invitation

An interactive ivory, gold and black envelope invitation for the introduction ceremony on 29th November 2026.

## Files

* `index.html` the whole invitation (envelope, animation, music control, WhatsApp share)
* `music/ire-instrumental.mp3` put the Iré (Adekunle Gold) instrumental here
* `og-image.jpg` preview picture shown when the link is shared on WhatsApp

## Adding the music

Save the instrumental as `music/ire-instrumental.mp3` (exact name, lowercase) and push it.
The music starts with a soft fade in when the guest taps the envelope.
If the file is not there, an "Add music" button appears so you can pick the file from your phone to preview it, but only you will hear that copy. Guests only hear the file in the `music` folder.

## Getting a shareable link

Turn on GitHub Pages (Settings, Pages, deploy from branch, root folder) or import the repo on Vercel or Netlify. Share the link it gives you on WhatsApp.
